下载命令（统一下载引擎 V3.1）：

任务管理：
/dls              - 📊 列出所有下载任务（自动下载+频道下载+收藏夹），带任务编号
/dls #xxx         - 📋 查看任务 #xxx 详情：文件列表、下载速度、当前下载文件、预计剩余
/dl_stop #xxx     - ⏸ 完全停止任务 #xxx（停止扫描+停止下载+停止监听新消息，重启后仍保持暂停）
/dl_continue #xxx - ▶️ 完全恢复任务 #xxx（恢复扫描+恢复下载+恢复监听新消息，从断点继续）
/dl_no #xxx       - ⏹ 取消并删除任务 #xxx（清理数据库记录）
/dl_clear         - 🧹 清理所有已完成和已取消的任务记录

新建下载：
/dl [链接] [筛选变量/消息ID] - 📥 新建频道/群组下载任务（所有类型，一次性下载）
/dl_video [链接]              - 🎬 只下载视频（一次性下载）
/dl_photo [链接]              - 🖼️ 只下载图片（一次性下载）
/dl_watch [链接]               - 👁️ 持续监听群/频道（所有类型，新消息自动下载）
/dl_watch_video [链接]         - 🎬 持续监听群/频道，只下载视频
/dl_watch_photo [链接]         - 🖼️ 持续监听群/频道，只下载图片
/dl_saved                     - ⭐ 启动收藏夹监听（所有类型）
/dl_saved_video               - ⭐ 收藏夹只下载视频
/dl_saved_photo               - ⭐ 收藏夹只下载图片
/at                           - 🛡️ 查看自动下载引擎状态

/dl 命令支持两种模式（自动识别）：

【搜刮模式】第二个参数包含字母时触发
筛选变量（可组合使用）：
  all           - 下载全部（默认）
  关键字         - 下载匹配关键字的消息
  latest:N      - 只下载最新的 N 条，例如 latest:50
  from:日期     - 从指定日期开始，例如 from:2024-01-01
  to:日期       - 到指定日期为止，例如 to:2024-06-30
  min_id:N      - 从消息 ID N 开始
  max_id:N      - 到消息 ID N 为止

组合示例：
  /dl 链接 latest:100 视频        - 最新100条里匹配"视频"的
  /dl 链接 from:2024-01-01 to:2024-06-30  - 下载上半年的

【指定消息ID模式】第二个参数是纯数字/范围/逗号分隔时触发
  单个ID:   /dl 链接 12345
  ID范围:   /dl 链接 12345-12350
  多个ID:   /dl 链接 12345,12346,12347
  混合模式: /dl 链接 12345,12350-12355,12360

收藏夹下载：
/dl_saved              - 启动收藏夹持续监听（所有类型），保存到收藏夹的新媒体自动下载
/dl_saved_video        - 收藏夹只下载视频
/dl_saved_photo        - 收藏夹只下载图片
/dl_stop #编号         - 完全停止收藏夹监听（停止扫描+下载+新消息监听）
/dl_continue #编号     - 完全恢复收藏夹监听（从扫描断点继续）
/dl_no #编号           - 取消收藏夹监听并删除任务

说明：启动后持续监听收藏夹（Saved Messages），有新图片/视频/文件保存进来就自动下载。
监听任务有独立编号，可在 /dls 中查看，支持暂停/继续/取消。
重启后自动恢复监听状态。
注意：收藏夹监听只能同时运行一个（所有类型/只视频/只图片三选一）。

群/频道监听：
/dl_watch [链接]        - 持续监听指定群/频道（所有类型），新消息自动下载
/dl_watch_video [链接]  - 持续监听指定群/频道，只下载视频
/dl_watch_photo [链接]  - 持续监听指定群/频道，只下载图片
/dl_stop #编号          - 完全停止监听（停止扫描+下载+新消息监听）
/dl_continue #编号      - 完全恢复监听（从扫描断点继续）
/dl_no #编号            - 取消监听并删除任务

说明：逻辑和收藏夹监听完全一致，只是监听目标从收藏夹改成指定的群/频道。
首次执行会扫描该群/频道的历史消息并下载，之后持续监听新消息，有新图片/视频/文件自动下载。
监听任务有独立编号，可在 /dls 中查看，支持暂停/继续/取消。
重启后自动恢复监听状态。
支持同时监听多个不同的群/频道（每个有独立编号）。
链接支持：群/频道邀请链接、公开用户名（@xxx）、消息链接。

自动下载说明：
• 功能：直接将频道、群组或私聊中的图片/视频/文件【转发】给机器人，即可触发自动下载。
• 权限：仅管理员可用。
• 批次：3秒内连续转发的消息归为同一个任务，共享一个任务编号。
• 存储：文件按 [原始ID/频道名] 自动分类存入 download 目录。
• 管理：自动下载任务和命令下载任务统一管理，/dls 可查看，支持暂停/继续/取消。
• 过滤：只处理真正的文档和图片，链接预览、投票、位置等不触发。

系统说明：
• 任务编号：每个下载任务都有唯一编号（#xxx），在 /dls 列表和创建通知中显示。
• 数据库驱动：所有任务和文件记录存入 SQLite，重启后自动恢复未完成的任务。
• 扫描进度持久化：扫描中途关闭/重启，从上次扫描到的消息ID接着往旧扫，扫完后才更新断点，不会重头扫。
• 收藏夹增量：首次 /dl_saved 全量扫描，后续启动只扫上次断点之后新增的消息。
• 群/频道监听：/dl_watch 逻辑和收藏夹完全一致，支持同时监听多个群/频道，每个有独立编号。
• 先扫后下：扫描完全完成后才开始下载，扫描中发现的新文件加到待下载队列。
• 同名文件去重：扫描阶段检查本地同名同大小文件，有就跳过不下载；下载阶段同名不同大小自动重命名（文件名(1).ext）。
• 下载速度：/dls #xxx 可查看实时下载速度、已下载/总大小、当前下载文件。
• 网络状态：自动检测断网/来网，断网时显示警告，来网后自动继续下载（扫描接着扫，下载接着下），不标记失败。
• 暂停的任务重启后不自动恢复，需手动 /dl_continue #xxx 继续。
• 下载并发：同时最多6个文件下载。
